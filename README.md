게임 정보와 상세 소개는 [한글화 발굴 아카이브](https://dollars-archive.github.io/Game-Localization-Discovery-Archive/game.html?file=platforms%2Fpsp%2Fgames%2Ftwelve-sengoku-fuushinden.md)에서 확인할 수 있습니다.
